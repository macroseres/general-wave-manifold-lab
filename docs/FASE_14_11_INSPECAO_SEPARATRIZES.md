# Fase 14.11 — Inspeção de separatrizes

- Clique sobre separatrizes finitas ou no infinito abre o cartão contextual da Variedade 3D.
- O cartão informa estabilidade, origem e índice do ramo exibido. O índice é apenas de renderização, não um identificador matemático canônico.
- As coordenadas exibidas são a posição aproximada da interseção do ponteiro com o objeto renderizado, não uma solução refinada da EDO.
- Nenhuma equação, curva calculada ou algoritmo numérico foi modificado.
- Validação local: `npm install`, `npm run check`, `npm run dev`.
