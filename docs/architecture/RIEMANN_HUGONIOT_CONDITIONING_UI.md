# Diagnósticos de condicionamento no Espaço de estados

O painel do trecho de Hugoniot associado ao candidato selecionado apresenta o tipo de raiz numérica, a inclinação normalizada do determinante, a separação paramétrica para outra raiz detectada e o resultado das perturbações dos dez coeficientes do fluxo quadrático. Dados ausentes são explicitamente indicados.

Os diagnósticos só aparecem quando o trecho correspondente foi identificado. A inclinação é uma medida numérica dependente da parametrização e da escala; a sensibilidade é um experimento local de diferenças finitas. Nenhum desses indicadores certifica bifurcação ou admissibilidade entrópica.
