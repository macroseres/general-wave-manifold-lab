# Etapa 8 — painel de inspeção 3D

O painel direito permanece exclusivo do ambiente Variedade 3D. Seus resultados matemáticos não foram modificados; apenas a estrutura de apresentação foi organizada em nove seções expansíveis:

1. Inspeção de P ∈ W (aberta por padrão)
2. Espectro de Rankine–Hugoniot
3. Equações sônicas no ponto
4. Rarefação no ponto
5. Singularidade selecionada
6. Singularidades finitas da rarefação
7. Singularidade no infinito
8. Cartas
9. Degenerações

As expressões e condicionais de cada diagnóstico permanecem intactas. A seção do ponto selecionado é a única aberta por padrão para evitar uma coluna excessivamente longa. A apresentação compacta usa elementos HTML `details`/`summary`, com suporte nativo a teclado.

Em telas estreitas, a regra anterior que oculta o painel de inspeção permanece inalterada. Uma futura revisão responsiva poderá oferecer um painel móvel sem sobrepor a visualização.
