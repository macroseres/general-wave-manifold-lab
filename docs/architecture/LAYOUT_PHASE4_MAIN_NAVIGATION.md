# Layout — etapa 4: navegação principal

A variedade 3D é o ambiente principal. Espaço de estados e Espaço físico são acessados diretamente no cabeçalho e continuam compartilhando a seleção de candidatos.

As ações de importar/exportar e restaurar o preset estão no menu **Experimento**; tema e ajuda estão em **Preferências**. Os controles existentes foram preservados, inclusive o campo de importação JSON, e não houve alteração nas rotinas matemáticas.

A barra usa elementos semânticos `nav` e `details` para navegação por teclado. As operações continuam explícitas, sem execução automática ao abrir um menu.
