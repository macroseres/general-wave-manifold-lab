# Inspeção sincronizada de candidatos de Riemann

A seleção de uma cadeia candidata é compartilhada pelos painéis **Espaço de estados** e **Espaço físico**. A tabela física e o seletor de estados apontam para o mesmo índice na lista ordenada de candidatos.

No plano de estados, a trajetória do leque amostrado aparece em azul, enquanto cada choque é representado por um segmento laranja tracejado entre os respectivos estados laterais. Os marcadores indicam U_L, U_M e U_R. O botão no painel físico abre a inspeção no plano de estados.

Os segmentos de choque no plano de estados são **representações de conexão entre estados**, não trajetórias integrais. Os perfis físicos continuam sendo U(x/t) amostrados. A escolha é manual e não certifica admissibilidade ou unicidade entrópica.
