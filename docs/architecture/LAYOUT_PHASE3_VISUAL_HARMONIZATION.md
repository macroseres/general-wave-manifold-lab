# Layout — etapa 3: harmonização visual

A interface do Espaço de estados e do Espaço físico passa a compartilhar a mesma gramática visual de seções expansíveis (`scientificDisclosure`), controles (`scientificControlBar`) e tabelas (`scientificTableRegion`).

A intervenção é exclusivamente de apresentação: não modifica cálculos de Rankine–Hugoniot, Lax, Liu, convergência, sensibilidade ou seleção das cadeias. Acessibilidade: estados expandidos e foco visível, alvos mínimos de 44 px e respeito a `prefers-reduced-motion`.

Os diagnósticos continuam separados da área principal de visualização e nenhuma evidência numérica passa a ser classificada como certificação entrópica.
