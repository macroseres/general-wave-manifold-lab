# Fase 15.27 — Painéis laterais por atividades

- Variedade 3D: barra de atividades para geometria, objetos, vista e estados.
- Inspeção 3D: barra de atividades para ponto, ondas, singularidades e cartas.
- Espaço físico: barra de atividades para perfis, tempo e configurações.
- Não modifica equações, cálculos ou estados científicos.
- Os controles continuam no DOM e apenas a apresentação é filtrada por categoria.
- A interface móvel mantém as seções visíveis.
- Validação completa requer dependências npm instaladas.
