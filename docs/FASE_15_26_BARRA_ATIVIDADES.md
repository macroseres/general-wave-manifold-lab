# Fase 15.26 — Barra de atividades

Barra vertical com Estados, Curvas, Vista e Cadeias (esta última somente se houver candidatas). Clique em uma categoria para abrir seu painel; clique novamente para recolher. Botão inferior recolhe/expande. O gráfico e a inspeção direita são preservados. O painel esquerdo usa rolagem interna. Em telas menores, o painel aparece acima do gráfico.

Não foram alterados os cálculos ou estados matemáticos. Conferir `npm run check`, seleção de estados, painéis recolhidos, zoom e responsividade.
